# AniHub — аниме онлайн: каталог, плеер, совместный просмотр

Всё приложение — **в одном файле** `index.html` (внутри уже встроен и прокси, и иконка, и P2P-комнаты).

## Вариант 1. GitHub Pages — только этот файл

1. Создайте репозиторий → загрузите `index.html` и `.nojekyll`.
2. Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.
3. Сайт: `https://ваш-ник.github.io/имя-репо/`

Что работает сразу, без сервера:
- каталог 3-в-1 (Shikimori → AniList → AniLibria), поиск, расписание с таймерами;
- **AniLibria: чистые потоки 480/720/1080 без рекламы** — сразу;
- **Kodik: чистые прямые потоки** — сайт сам резолвит их из браузера через публичные CORS-прокси (медленнее, чем с локальным прокси; если публичные прокси заняты — включится встроенный плеер Kodik);
- **совместный просмотр между устройствами** — P2P-комнаты (PeerJS), пока открыта страница ведущего;
- история, сезоны, фильмы, аватарки.

## Вариант 2. Максимум: + локальный прокси

Прокси уже встроен в `index.html`: **Профиль → Настройки → раздел Kodik → «⬇️ Скачать kodik_proxy.py»**.
Положите скачанный файл рядом с `index.html` и запустите `python3 kodik_proxy.py` → `http://localhost:8080`:
- чистые потоки Kodik мгновенно и стабильно + автоматическое вырезание рекламных сегментов из HLS;
- серверные комнаты (переживают закрытие вкладки ведущего, хранятся в rooms.json);
- доступ с устройств домашней сети: `http://IP:8080`.

На Pages-версии можно открыть сайт с `?proxy=http://IP-компа:8080` — он запомнит и будет брать потоки с вашего ПК.

## Вариант 3. Комнаты с демонстрацией экрана (Render + Socket.IO)

Комнаты умеют показывать экран ведущего всем зрителям (WebRTC) и зажигать красный тег
`● SCREEN SHARE` у ника. Для сигналинга нужен маленький Node-сервер — `server.js` в репозитории.

**Деплой на Render (5 минут, бесплатно):**
1. Залейте репозиторий на GitHub (он уже содержит `server.js`, `package.json`, `render.yaml`).
2. render.com → **New → Web Service** → подключите репозиторий.
3. Настройки подхватятся из `render.yaml` (Build: `npm install`, Start: `node server.js`). Create.
4. Получите URL вида `https://anihub-rooms-xxxx.onrender.com`.

**Подключить URL к AniHub (любой из способов):**
- впишите его в `anihub.html`: константа `ANIHUB_ROOMS_SRV = 'https://anihub-rooms-xxxx.onrender.com'`;
- или в консоли браузера: `localStorage.setItem('ah:roomSrv','https://anihub-rooms-xxxx.onrender.com')`.

**Keep-alive.** Пока сайт открыт хотя бы у одного посетителя, страница сама пингует `GET /api/ping` каждую минуту — бесплатный инстанс Render не засыпает. Проснутся ему придётся только если сайт никто не открывал ~15 минут.

Дальше всё само: при входе в комнату AniHub шлёт `GET /api/ping` (таймаут 60 сек — за это время
просыпается заснувший бесплатный инстанс Render), пока ждёт — показывает плашку
«Соединение с сервером…», после ответа поднимает Socket.IO.

Без сервера комнаты продолжают работать (P2P-синхронизация плеера и чат) — просто без
демонстрации экрана и тегов. Локальный прокси `kodik_proxy.py` тоже отвечает на `/api/ping`.

**Кнопки в шапке комнаты:** `🖥 Показать экран` (getDisplayMedia → WebRTC каждому зрителю),
`📷 + Камера (PiP)` — маленькое окно камеры в углу поверх экрана. Зрители видят сцену
прямого эфира под плеером и тег `● SCREEN SHARE` рядом с ником ведущего.
